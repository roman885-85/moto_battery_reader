# APLI4493C — сторонній аналог PMNN4493A, доданий як еталон

> Дамп надіслав власник для додавання моделі у бібліотеку відновлення.

Що показав розбір:

| | |
|---|---|
| заголовок | Σ = 0x41 ✅ |
| профіль `0x021..0x040` | Σ = 0x00 ✅ |
| паспортна ємність | `0x008` = 124 → **3100 мА·год** |
| запис моделі `@0x148` | `APLI4493C` |
| KIT-рядок у заголовку | `PMNN4493A` — та сама платформа |
| COPYRIGHT | `COPYRIGHT2015MOTOROLASOLUTIONS` |
| блоків | 23, з них 19 із Σ=0x5A |
| шунт DS2438 | **22.12 мОм** |

⚑ **Шунт свій.** У PMNN4493A він 24.90 мОм, тут 22.12 — тож брати еталон
4493A для цієї моделі не можна: струм, залишок і знос вийшли б неправильні.
Саме заради цього модель і додано окремо, а не як псевдонім.

Дамп у теці — **як прийшов**, із навченими даними донора. У `templates.h`
лежить його очищена версія: навчені значення в блоках хвоста обнулені, суми
перераховані (див. `TPL_APLI4493C_33` і `TPL_APLI4493C_FRESH`).
