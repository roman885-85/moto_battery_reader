# 📼 Архів дампів акумуляторів Motorola IMPRES

Реальні дампи, зібрані під час розробки цього інструмента: **робочі** (рація приймає як
справні IMPRES) і **несправні** (визначаються як невідомі, не заряджаються, не вмикаються),
а також дампи з **експериментів** — до/після скидання, рекалібрування, заміни елементів,
часткового стирання та перепрошивки чужим шаблоном.

Це фактична доказова база, на якій побудовані `templates.h`, правила Майстра відновлення
(`recovery.h`) і рецепт підготовки до рекалібрування.

## Що всередині

Кожна тека = одне спостереження власника:

- **`notes.md`** — опис **дослівно словами власника**: стан АКБ, що показує рація або ЗП,
  що робили перед зняттям дампа. Змінено лише одне — довгі hex-блоки замінено посиланнями
  на файли, щоб текст лишався читабельним.
- **`files/*.bin`** — самі дампи: `NN_<модель>_2433.bin` (512 Б, EEPROM DS2433) і
  `NN_<модель>_2438.bin` (64 Б, монітор DS2438). Однаковий номер `NN` = той самий АКБ.

> ⚠️ **Прив'язка опису до АКБ.** У вихідних повідомленнях опис стану стоїть **перед**
> блоком «Модель / Серійний / дампи», якого він стосується. Саме тому поруч із бінарниками
> збережено `notes.md` **цілком** — щоб зв'язок «опис ↔ дамп» можна було перевірити за
> оригіналом, а не покладатися лише на назву файла.

## Як читати дамп

```bash
python tools/decode_dump.py dumps/02-katalog-osnovnyi/files/01_PMNN4493A_2433.bin \
       --ds2438 dumps/02-katalog-osnovnyi/files/01_PMNN4493A_2438.bin

# звірити з вшитим еталоном (genuine vs клон)
python tools/decode_dump.py --template PMNN4409B          # -> ref_33.bin / ref_38.bin
python tools/decode_dump.py dumps/.../XX_2433.bin --diff ref_33.bin
```

## Зведення

Усього **58** акумуляторів, **66 дампів** (два пакети зняті двічі — до і після
зарядної станції; 131 файл: DS2433 + DS2438).

| Формат прошивки | Шт. |
|---|---|
| 2014 | 9 |
| 2017 | 11 |
| 2021 | 3 |
| не визначено (стертий / нетиповий) | 26 |

Заголовок DS2433 валідний (Σ≡0x41) у **64** із **66** дампів. Невалідних два:

* `01-katalog-pershyi/10` (Σ=0x00) — той АКБ, який власник позначив як
  **можливу китайську копію** (PT4409A);
* `20-vymahaie-vidnovlennya/03` (Σ=0x8E) — робочий пакет (індикація заряду
  працює), у якого зіпсовано рівно два байти: сама сума `0x1F` і байт `0x20`.
  Саме на ньому знайшлася хибна діагностика «станція почала добудову»
  (див. `notes.md` тієї теки).

## Призначення

- **Не** для клонування чужих акумуляторів: прошивка прив'язана до **моделі**, а не до
  серійника, і дампи викладені як матеріал для діагностики та ремонту **власних** АКБ.
- Порівняння «робочий проти зіпсованого» — основний спосіб перевіряти зміни у проєкті без
  деградації: саме так відлагоджено контрольні суми, дзеркало DS2438↔DS2433 і блок навченої
  калібровки `0x1B0–0x1FF`.
